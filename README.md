# homebrew-streeem

Homebrew tap for [streeem](https://github.com/3moeslam/streeem).

## Install

```sh
brew tap 3moeslam/streeem
brew install streeem
```

The `Formula/streeem.rb` file in this repo is auto-generated by the
[release workflow](https://github.com/3moeslam/streeem/blob/master/.github/workflows/release.yml)
in the streeem repo via [cargo-dist](https://github.com/axodotdev/cargo-dist).
Don't edit it by hand — your changes will be overwritten on the next release.
